# TurnaroundSync concept preview

Local responsive React/Vite prototype. No operational aviation system, live integration, real authentication, analytics, payment or form-delivery service is connected.

## Run

`npm install`

`npm run dev`

Local preview: http://127.0.0.1:4173

`npm run build` produces the deployable static client and supplied hosting worker. `npm run test:sites` verifies static assets, route fallback and packaging. Deployment and domain connection have not been performed.

## Approved visual directions

1. Apron Sculpture: homepage. Ivory, brass, Source Serif 4, original aircraft diorama, source cards and one horizontal scroll chapter.
2. Night Shift: five product pages, synthetic workbench and report/access scenes. Graphite, warm lighting, bold Inter headings, actual structured product UI.
3. Evidence Atlas: platform, solutions, knowledge and supporting pages. Forest text, coral emphasis, original fictional airport model and source readout.

Shared brand, favicon, navigation, footer, source labels and advisory boundaries unite the directions. Brand/trademark availability is not established.

## Included

Home; product portfolio and five module pages; platform; three stakeholder solutions; pricing hypothesis; demo, trial and contact intake; ten-record synthetic workbench and read-only report; company; six research resources; trust, integration requirements, features, evaluation, access help, privacy, terms and 404.

Forms validate only in browser memory and explicitly state that nothing is sent. Demo review actions affect local fictional state only. Reload resets the review queue. The report is a fixed baseline snapshot and explicitly states it does not reflect temporary queue edits.

## Motion

GSAP coordinates hero entrances, staggered card/text reveals and the homepage incident's pinned horizontal translation. Lenis supplies smooth wheel scrolling and anchor navigation. Narrow/short screens get stacked incident chapters. CSS and JavaScript respect prefers-reduced-motion; animation does not initiate external operations.

## Source files

- `src/App.jsx`: page components, routing, animation and local interactions.
- `src/data.js`: five exact module mappings, stakeholders and ten synthetic records.
- `src/resources.json`: retained research, schema, rights checklist, storyboard, outreach and scorecard.
- `src/styles.css`: shared tokens and responsive theme styles.
- `public/images`: original AI-generated fictional scenery, brand raster and optimized WebP assets. These are illustrations, not airport footage or operational evidence.
- `public/licenses`: bundled typeface license notices.
- `qa`: real browser captures and combined source/implementation comparison.
- `design-qa.md`: comparison history, checks and limitations.

## Before public launch

Supply approved legal entity/contact details, production legal policy, actual form delivery and consent handling. Confirm brand rights, accessibility, security and deployment configuration. No fabricated customer/ROI/security claims are included. All five modules and the $5,000 / four-week / one-stand trial are proposed hypotheses. All substantive aviation use requires written triad permissions, safety/security review and paid shadow-trial evidence.
